# Source notes from kuai

These examples are from [yslib/kuai at 2b883e6295a9d04e672749ba0df1fd16836a6fb6](https://github.com/yslib/kuai/tree/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp). Check the target branch before reusing a symbol. Use the observed mechanism as evidence, and apply the user's project choices when adopting it.

| Design choice | Evidence in the runtime |
| --- | --- |
| Modules follow one layout and aggregate into deliverables | `kurt_add_module` validates include/private subdirectories and defaults to object modules. Runtime explicitly requests internal core access. The C surface sets `TARGET_NAME kurt` and assembles the host product. [KurtUtils.cmake](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/cmake/KurtUtils.cmake) · [runtime target](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/runtime/CMakeLists.txt) · [C API target](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/kuai_c/CMakeLists.txt) |
| Keep declarations close to their consumers | A public type and its out-of-line definitions form a pair. A private factory manages device construction while the public header exposes a backend-neutral device. [KuSlice.h](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/core/include/kuai/core/KuSlice.h) · [KuSlice.cpp](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/core/src/KuSlice.cpp) · [KuDevice.h](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/core/include/kuai/core/KuDevice.h) · [KuDeviceAccess.h](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/core/private/core/KuDeviceAccess.h) |
| Target-specific language support and formatting | The build selects different C++ modes for MSVC and the other branch. The formatter records project choices including four-space indentation and a 120-column limit. [Build options](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/cmake/KurtBuildOptions.cmake) · [.clang-format](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/.clang-format) |
| Return explicit errors in the appropriate layer | A private factory returns `std::expected<std::unique_ptr<KuDevice>, ku_status_t>`. The public types header defines fixed-width status values and uses an X-macro catalog. The NVIDIA adapter classifies cuBLAS and cuSOLVER errors. [Private factory](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/core/private/core/KuDeviceAccess.h) · [Status catalog](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/kuai_c/include/kuai/kuai_c/ku_types.h) · [Vendor error translation](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/vendor/nvidia/include/vendor/KuVendorStatus.h) |
| Bridge runtime dispatch to static vendor code | The host calls `stream_create(ctx, out)`. A vendor entry returns the module descriptor, and a template builder installs specialized thunks. A separate compile-time vendor trait selects native algorithms when the vendor is known. [C operations table](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/kuai_c/include/kuai/kuai_c/ku_runtime.h) · [Host call](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/core/src/KuDevice.cpp) · [NVIDIA entry](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/vendor/nvidia/runtime/KuVendorModule.cu) · [Thunk builder](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/vendor/include/kuai/vendor/KuVendorTraits.h) · [Static algorithm binding](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/vendor/include/kuai/algorithm/algorithm_vendor.h) |
| Use typed handles, borrowed views, and intrusive ownership | Private traits mediate C/C++ handle conversion. Reference-count operations and C++ RAII are distinct from object classification. The C completion header specifies callback and wait lifetimes. [Handle conversion](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/core/include/kuai/core/KuCHandle.h) · [Refcount](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/core/include/kuai/core/KuRefCounted.h) · [Owning pointer](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/core/include/kuai/core/KuPointer.h) · [Completion contract](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/kuai_c/include/kuai/kuai_c/ku_completion.h) |
| Explicit type tags and flat binary dispatch | The object hierarchy uses checked casts and registered kinds. For binary spans the runtime maps each dtype to a dense index, builds the pair key, and recovers two C++ types in a specialized arm. [RTTI](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/core/include/kuai/core/KuRtti.h) · [Type normalization](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/vendor/include/kuai/vendor/KuTypeVisit.h) · [Pair dispatch](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/vendor/include/kuai/vendor/KuObjectView.h) · [Static switch](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/vendor/include/kuai/vendor/KuStaticSwitch.h) |

**Known implementation debt.** At this revision `KU_STATUS_CHECK` throws, `invokeBoundary` catches, and some private factories still use throwing allocation. The desired low-level profile disables exceptions and propagates failures explicitly. Do not copy these exception paths into a new runtime. [Throwing check](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/core/include/kuai/core/KuCore.h) · [Current boundary wrapper](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/kuai_c/private/kuai_c/KuCApiMethod.h) · [Current pool factory](https://github.com/yslib/kuai/blob/2b883e6295a9d04e672749ba0df1fd16836a6fb6/kurt-cpp/src/core/private/core/KuNativeMemoryResource.h)
